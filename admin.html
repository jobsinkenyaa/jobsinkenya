📖 Manual Upload (backup method)

3. Click Add file → Upload files
4. Drag in jobs.json → Click Commit changes

🔑 GitHub Settings

Required for one-click publishing. Saved only in this browser.
How to get a GitHub Token:
1. Go to github.com → click your profile photo → Settings
2. Scroll to the bottom → Developer settings
3. Personal access tokens → Tokens (classic)
4. Click Generate new token (classic)
5. Expiration: No expiration · Tick ✅ repo
6. Click Generate token → copy it immediately!
